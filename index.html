Wortarten-Training

Tippe ein Wort an und wähle seine Wortart. Wenn jedes Wort eine Wortart hat, kannst du deinen Satz prüfen.

Das Programm startet nicht. Auf diesem Gerät läuft gerade kein JavaScript. Öffne die Seite im Browser (Safari oder Chrome), nicht in einer Vorschau.

Stufe wählen

Satz 1 0 von 0 Wörtern richtig

Welche Wortart ist das? Tippe auf die passende Wortart.

Mit der Tastatur: Pfeiltasten wechseln das Wort, die Taste auf dem Button wählt die Wortart, Entf löscht.
